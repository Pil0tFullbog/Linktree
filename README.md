# Pil0t_Fullbog Linktree

Eine übersichtliche persönliche Linktree-Seite für **Pil0t_Fullbog**. Hier sind Social-Media-Profile, Community, Projekte und weitere wichtige Links an einem Ort gebündelt.

## Live-Version

Die aktuelle Seite ist unter [pilot-links.duckdns.org](https://pilot-links.duckdns.org) erreichbar.
Die Website ist öffentlich und kann von jeder Person ohne Anmeldung oder privaten Zugang aufgerufen werden.

## Enthaltene Links

- GitHub
- Discord
- TikTok
- YouTube
- Disboard
- Twitch
- Spotify

## Technik

Das Projekt ist eine schlanke statische Website ohne Frameworks oder externe Abhängigkeiten:

- `index.html` - Seitenstruktur und Links
- `style.css` - Layout, Farben, Hover-Effekte und responsive Darstellung
- `CNAME` - konfigurierte eigene Domain
- `image.png` - Profilbild

## Lokal starten

Da es sich um eine statische Seite handelt, genügt es, `index.html` im Browser zu öffnen. Für eine realistischere lokale Umgebung kann auch ein beliebiger lokaler Webserver verwendet werden.

## Anpassen

Links und Texte können direkt in `index.html` geändert werden. Farben, Abstände und das responsive Verhalten werden in `style.css` angepasst.
