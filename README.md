## Was dich erwartet

- dunkles, fokussiertes Design mit farbigen Link-Buttons
- responsive Darstellung für Desktop und Smartphone
- dezente Hover-Effekte für ein lebendiges Interface
- direkte Links zu GitHub, Discord, TikTok, YouTube, Disboard, Twitch und Spotify
- öffentlich erreichbar, ohne Anmeldung oder privaten Zugang

## Projektstruktur

```text
.
├── index.html                 # Seitenstruktur und Links
├── style.css                  # Layout, Farben und responsive Design
├── image.png                  # Profilbild
├── CNAME                      # Eigene Domain
└── .github/workflows/pages.yml # Automatisches GitHub-Pages-Deployment
```

## Lokal starten

Für einen schnellen Blick genügt es, `index.html` im Browser zu öffnen. Alternativ kann ein beliebiger lokaler Webserver verwendet werden.

```bash
python -m http.server 8000
```

Danach ist die Seite unter `http://localhost:8000` erreichbar.

## Anpassen

1. Links, Profilname und Beschreibung in `index.html` ändern.
2. Farben, Abstände und Hover-Effekte in `style.css` anpassen.
3. Änderungen nach `main` pushen.

GitHub Pages veröffentlicht die Website danach automatisch über den Workflow in `.github/workflows/pages.yml`.
